### Git 与 GitHub 操作统一使用 7890 端口

构建最新版 release、向 GitHub 提交，以及其他涉及网络访问的 Git 操作，必须统一通过本机 7890 端口代理执行，避免因代理配置不一致导致构建发布或 Git 操作失败。
